## How I approach work

1. **Understand the problem** — clarify the objective, stakeholders, constraints and current process.
2. **Define the work** — document requirements, data needs, process steps and acceptance criteria.
3. **Build or analyse** — develop the workflow, prepare the data or create the reporting view.
4. **Validate** — test assumptions, check outputs and document limitations.
5. **Communicate** — present findings, decisions, handover notes and next steps clearly.
